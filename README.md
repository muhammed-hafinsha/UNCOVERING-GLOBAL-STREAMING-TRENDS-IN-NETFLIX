# UNCOVERING-GLOBAL-STREAMING-TRENDS-IN-NETFLIX


## Overview
An exploratory data analysis (EDA) project exploring Netflix's content library to uncover patterns in content distribution, release years, genres, ratings, and geographical production.

## Objectives
- Analyze the distribution of Movies and TV Shows.
- Explore content ratings and target audiences.
- Identify the most common genres and leading production countries.
- Examine release-year trends and content additions.
- Extract insights that can support content strategy analysis.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and missing-value handling
- Feature engineering using date-related variables
- Univariate and bivariate analysis
- Genre and country distribution analysis
- Content rating analysis
- Release-year and content-type comparisons
- Statistical visualizations using bar charts, histograms, pie charts, and violin plots

## Key Insights
- Movies account for approximately 70% of the catalog represented in the analysis.
- TV-MA and TV-14 are prominent content ratings.
- The United States, India, and the United Kingdom are leading countries by representation.
- Genre and release-year distributions reveal differences in Netflix's content library.
